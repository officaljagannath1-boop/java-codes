 use of try keyword: "The `try` keyword is used to define a block of code that might throw an exception.
  It is always used in conjunction with `catch` and/or `finally` blocks to handle exceptions that may occur 
  during the execution of the code within the `try` block."


  use of catch keyword: "The `catch` keyword is used to define a block of code that handles exceptions thrown in the associated `try` block.
  It allows you to specify the type of exception you want to catch and provides a way to respond to the error, such as logging the error,
   displaying a message to the user, or performing cleanup operations."
